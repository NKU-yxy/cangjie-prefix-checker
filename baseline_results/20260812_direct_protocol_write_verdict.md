# 逐 token 直接协议写入候选验收报告

- 优化名称：用带短写/`EINTR` 重试的 Linux `write` 替代 iostream flush
- 目标瓶颈：减少画像中 33,831 次 token 协议输出的用户态封装开销
- 对照提交：`fc9ffe81626c3c88004c90e3e5ca7d8fdae955e5`
- 候选提交：`f47d93822385c73bd3e75ee6c3dc1ace9f9e8c40`
- 是否改变协议：否；仍每 token 立即输出一个 `0/1` 及换行，未批量、未延迟
- 是否改变依赖或编译参数：否；使用通用 POSIX/Linux 接口
